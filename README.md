# 席替えボード

ブラウザだけで使える席替え用アプリです。名簿を貼り付けて席替えし、固定席やドラッグでの入れ替えを調整できます。

## 使い方

1. `index.html` をブラウザで開きます。
2. 最初に席替え結果画面が開きます。
3. クラスや席の形を変える場合は `初期設定` を押します。
4. 初期設定画面では `決定` を押してメイン画面に戻ります。
5. メイン画面の `スタート` を押して席替えを開始します。
6. 必要なら席をクリックして固定、ドラッグで入れ替えます。
7. `この結果を確定して保存` を押し、結果名を入力すると履歴に保存されます。
8. 必要に応じて PNG、SVG、CSV を出力します。

## 初期設定

- `基本情報`: タイトル、前回の席替え結果を設定します。
- `席の形`: 行・列を設定し、プレビュー上の席をクリックして空席位置を直接指定できます。
- `メンバー管理`: 1人ずつ追加・削除できます。まとめて編集もできます。
- `前方優先`: 固定席の次に優先して、選んだ人を前から1列目または2列目に配置します。
- `先生用`: 別タブで非表示条件を設定できます。固定席もここで座席表をクリックして指定します。席替えには反映されますが、結果表示画面には表示されません。
- `先生用` タブはパスワードで保護されます。開くたびに入力が必要です。
- 席替え画面の `初期設定` ボタンから、あとでメンテナンスに戻れます。
- 結果画面の音量スライダーで、ドラムロール効果音の音量を調整できます。

## ブラウザ内保存

入力した名簿、席の形、空席位置、常時固定席、条件設定、確定した席替え履歴はブラウザの `localStorage` に自動保存されます。同じブラウザで次回開くと復元されます。

保存を消したい場合は、先生用タブの `localStorageを消去` を押します。

別端末へ移したい場合は、先生用タブの `保存データをダウンロード` でJSONファイルを書き出し、別端末で `保存データを読み込む` からそのファイルを選びます。

## 席替え履歴

結果表示画面の下にある `この結果を確定して保存` を押すと、名前を付けて現在の座席表を保存できます。保存した結果は `席替え履歴` の `表示` から見返せます。

## 条件設定

- 各条件の `選択` / `グループ作成` / `ペア作成` ボタンを押すと、名簿の人をボタンで選べます。
- `この人は前1列目`: 対象者を複数選んで保存します。
- `前1、2列のどこか`: 対象者を複数選んで保存します。
- `前後左右で隣り合わない`: 2〜5人を選んでグループ追加します。
- `前回の席替え結果`: 初期設定の基本情報で保存済み結果を選ぶと、その結果で左右隣だった人同士が今回も左右隣にならないようにします。

固定席と条件が矛盾する場合や席数に余裕がない場合は、完全には守れないことがあります。

## 出力

- PNG: 16:9、1600x900pxの画像として書き出します。
- SVG: 拡大してもきれいなベクター画像です。
- CSV: 座席番号、行、列、名前、固定状態を表形式で確認できます。

ネットワーク接続やサーバーは不要です。
